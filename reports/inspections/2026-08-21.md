## Root-cause analysis

The root cause is confined to the inspection routine's environment, and is
two independent gaps that both must be closed:

1. **No Railway API reachability.** The agent proxy denies `CONNECT` to
   `backboard.railway.com:443` (HTTP 403, policy). Confirmed via the proxy
   status endpoint above — a deterministic allowlist denial, identical every
   day, not a network flake.
2. **No Railway credential.** Even if the host were reachable, there is no
   `RAILWAY_API_TOKEN` in the environment and no Railway MCP server connected,
   so neither the GraphQL fallback nor the preferred MCP path could
   authenticate.

No source-code fault in `apps/` or `packages/` is implicated — nothing in the
application repo can grant this routine egress or a token. (For reference, the
production deploy target per `CLAUDE.md` is `origin/main`, currently v1.70.3;
the `prod` branch named in this routine's infra brief was retired 2026-07-20
and its head has not moved since, consistent with that note.)
