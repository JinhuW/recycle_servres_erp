## Root-cause analysis

For context once access is restored, PR #113 (merged into today's release)
touched:
- `apps/backend/src/lib/uploads.ts` (or equivalent `isUploadPath` check) —
  the route serving line-photo uploads was previously missing from the
  allowlist, causing real (>1 MiB) phone photos to 413 before reaching the
  resize handler. Worth confirming no 413s appear against the new upload
  path post-release.
- `orders.total_cost` derivation — now separates `qty` (current) from
  `qty_purchased` (original, via migration `0088`) so a PO's recorded cost
  no longer shifts when stock sells. Worth confirming `services/orderGoodsTotal.ts`
  isn't throwing on orders written before `0088` backfilled `qty_purchased`.
- Part-number canonicalization (migration `0089`, rebuilding the
  `ref_prices` index) — a stricter separator rule now requires a delimiter
  after `P/N`, `S/N`, `PART` prefixes. Worth confirming no OCR/import path
  still emits the old un-delimited form and gets silently mis-keyed or
  rejected.

None of this is a claim that these are broken — only that they are the
highest-value places to look first once Railway access exists, since
they're the newest, most invasive changes in the window this report covers.
