Root cause is confined to the inspection routine's own environment, unchanged
from prior reports:

1. **No Railway API reachability.** The agent proxy denies `CONNECT` to
   `backboard.railway.com:443` (HTTP 403, policy) — a deterministic allowlist

   `RAILWAY_API_TOKEN` in the environment and no Railway MCP server connected,
   so neither the GraphQL fallback nor the preferred MCP path could
   authenticate.

application repo can grant this routine egress or a token. Per `CLAUDE.md`,
