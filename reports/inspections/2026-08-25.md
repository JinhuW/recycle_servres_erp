## Root-cause analysis

Root cause is confined to the inspection routine's own environment,
unchanged from prior reports:

1. **No Railway API reachability.** The agent proxy denies `CONNECT` to
   `backboard.railway.com:443` (HTTP 403, policy) — a deterministic
   allowlist denial, identical every day, not a network flake.
2. **No Railway credential.** Even if the host were reachable, there is no
   `RAILWAY_API_TOKEN` in the environment and no Railway MCP server
   connected, so neither the GraphQL fallback nor the preferred MCP path
   could authenticate.

No source-code fault in `apps/` or `packages/` is implicated — nothing in
the application repo can grant this routine egress or a token. Per
`CLAUDE.md`, production deploys from `origin/main`, now `v1.89.0` (updated
today via #177, previously stale at v1.70.3 for 6 days); the `prod` branch
named in this routine's infra brief was retired 2026-07-20 and its head has
not moved since, consistent with prior reports.
