Not performed against real logs — none were reachable. Three releases landed on `main` (production) since yesterday's report, all sell-order Pack-mode work (RS-204/RS-205/RS-206), per `CHANGELOG.md`:

- **v1.228.0 (RS-204)** — Pack mode "sinks" packed products to the bottom of the list and the tick writes the running count onto a Draft as it's counted.
- **v1.229.0 (RS-205)** — Pack mode can apply all flagged short counts to the order in one batch action.
- **v1.230.0 (RS-206)** — adds a **Packing** status between Draft and Shipped (stock-check deferred until Shipped/Awaiting payment/Done, so opening Pack mode can't fail on a rival's stock claim), and changes order-line numbering so a product added once packing has begun takes the next sequential # instead of renumbering the whole order (new `sell_order_lines.append_batch` column, migration `0166_sell_order_lines_append_batch.sql`).

None of these is a schema change with destructive or backfill DDL — migration 0166 is an additive nullable column.
